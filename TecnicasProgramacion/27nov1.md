# Estructura mínima del proyecto

```
hola-genkit/
├─ package.json
├─ index.js
```

# Pasos (rápidos)

```bash
mkdir hola-genkit && cd hola-genkit
npm init -y
npm i genkit @genkit-ai/googleai
export GOOGLE_GENAI_API_KEY="TU_API_KEY"
node index.js
```

# package.json (importante: type module)

```json
{
  "name": "hola-genkit",
  "version": "1.0.0",
  "type": "module",
  "main": "index.js",
  "scripts": {"start":"node index.js"}
}
```

# index.js (mínimo)

```js
import { gemini15Flash, googleAI } from '@genkit-ai/googleai';
import { genkit } from 'genkit';

const ai = genkit({ plugins: [googleAI()], model: gemini15Flash });

async function main(){
  const { text } = await ai.generate('Di "Hola mundo" en español');
  console.log(text);
}

main().catch(e=>{ console.error(e); process.exit(1); });
```

Ejecuta `npm start`. Esto llamará a Gemini vía Genkit y mostrará el “Hola mundo” generado. ¿Quieres versión usando un flujo (`defineFlow`) o un endpoint HTTP?
